\# Exercise 9: Jenkins Multi-Stage Pipeline



\## Objective

Automate the build, testing, deployment, and application testing of a Python Flask application using a Jenkins Pipeline.



\## Technologies Used

\- Jenkins

\- Docker

\- Python

\- Flask

\- Git and GitHub



\## Pipeline Stages

1\. Build — install application dependencies.

2\. Test — execute unit tests.

3\. Deploy — copy the application to a deployment directory.

4\. Run Application — start the Flask application.

5\. Test Application — verify the application behavior.
